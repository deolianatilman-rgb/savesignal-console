Two systems, one continuous timeline — prediction before a disaster, and a self-healing relay network after one. Switch between phases below.

01

Sensing Layer

Existing Korean pet-wearables continuously capture heart rate, movement, and behavioral signals from both trained and domestic dogs.

02

Behavior Classification

An AI layer flags anomalous behavior in real time, treating animal reactions as a supplementary hazard signal alongside instrument data — not a replacement for it.

03

Fusion with Gov Data

Behavior signals combine with PAGASA's meteorological and seismic feeds into one prediction model — most valuable for earthquakes, where animals react before instruments trigger.

04

Public Early Warning

The fused model issues an early warning alert to the public — extending lead time beyond what either data source would give alone.

01

Any Device, One Mesh

Rescuer phones, wearables, and dog collars all run the same mesh-AI client, so whatever survives becomes part of the network.

02

Trained & Domestic Dogs Both Contribute

Trained rescue dogs actively search using AI-assisted bark and behavior detection; ordinary pet collars passively extend mesh coverage and help locate trapped pets.

03

Self-Healing Relay

Signals hop device-to-device over BLE (short-range) and LoRa (long-range fallback). If a hop point goes offline, the network reroutes automatically.

04

Built for the Worst Case

Designed to work even when there is no cellular network left to activate from — not degraded connectivity, zero connectivity.
